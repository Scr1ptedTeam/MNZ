# «Молодо не зелено!» — сайт XV школьного медиафестиваля

Статический сайт для GitHub Pages. Адаптивная вёрстка, обратный отсчёт до церемонии, номинации, этапы, требования и панель организатора.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий на GitHub.
2. Загрузите **всё содержимое** этой папки (index.html, style.css, app.js, config.json и assets/).
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/ (root)`.
5. Сохраните. Через минуту сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Панель организатора
Нажмите «ОРГАНИЗАТОРАМ» внизу сайта:
- меняйте текст, URL и активность кнопок;
- меняйте даты дедлайнов и дату/время финала;
- сохраняйте настройки в браузере;
- скачивайте новый `config.json`.

Чтобы опубликовать настройки для всех посетителей, замените `config.json` в GitHub новым скачанным файлом. После обновления GitHub Pages изменения увидят все.

**Важно:** панель работает на стороне браузера и не является защищённой серверной CMS. Локальное сохранение видно только в текущем браузере. Не вводите секретные данные. Для безопасного многопользовательского редактирования нужна отдельная серверная авторизация/база данных.
